# Original engine demo (frozen)

`motronic-bench.html` is the 2D engine demo exactly as it was before the
2026-08-09 visual rework — the simple cutaway with mid-bore combustion glow
and no valvetrain. It is one self-contained file: open it directly in a
browser, or run `npm run demo` from `cleanroom/` and visit `/classic`.

This is a frozen build, not a source tree. The current demos live in:

- `web/` — the improved 2D demo (`npm run demo`)
- `web3d/` — the three.js engine bay (`npm run demo:3d`)

The sources this bundle was built from are preserved in git only as this
artifact; the live `web/app/` sources have since moved on.
